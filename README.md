### 🚀 Highlighted experience: FoodBox 3.0 Central Server

Центральный backend-сервис платформы контроля блюд и план-меню.

**Что делал / делаю:**

- REST API на **Django + DRF** с архитектурой View / Service / Repository
- Модуль **AI**: датасеты, обучение моделей, мониторинг тренировок, prediction по фото блюд
- Интеграции со сторонними системами:
  - **r_keeper StoreHouse** — номенклатура, группы, документы, склады
  - **iiko** — синхронизация блюд и выгрузка заказов
  - **BI Analytics** — аналитические витрины и агрегаты
  - внешний **AI-сервис** — train / predict / model lifecycle
- Работа с объектным хранилищем (**S3-compatible**, SberCloud OBS): фото блюд, замеров, превью
- Фоновые задачи на **Celery + Redis + Beat** (синхронизации, отчёты, загрузки в S3)
- Отчётность: Excel / PDF (pandas, openpyxl, reportlab)
- Наблюдаемость через **Sentry**, документация API через **drf-spectacular**

**Также в стеке опыта:** разработка API на **FastAPI + SQLAlchemy** (типизация, async/sync endpoints, чистый слой доступа к данным).
